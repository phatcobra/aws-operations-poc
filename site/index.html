FOR CURIOUS VISITORS Technical details +

The public page is only a presentation layer. It receives a sanitized status snapshot; it cannot invoke the workload, inject a fault, or change AWS.

What runs the system

  • EventBridge starts the workload every hour.
  • Lambda runs the Python program.
  • DynamoDB keeps the attempt history.

How it stays observable

  • CloudWatch collects logs, metrics, and the operator dashboard.
  • GitHub Actions tests, deploys, and proves the live behavior.
  • Bounded recovery allows at most three attempts.

The operator dashboard inside AWS contains the detailed logs and alarm state. This public page intentionally shows only the information needed to understand the result.
