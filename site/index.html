WHEN SOMETHING GOES WRONG

It tries, but it does not get stuck.

The rule is simple: try the job, try again when it makes sense, then stop safely.

1

Try once

Ask the weather service for the current reading.

2

Try again

If there is a temporary problem, wait briefly and ask again.

3

Stop at three

If it still cannot get an answer, stop and write down the problem.

✓

The important part: the helper is allowed to recover, but it is never allowed to keep trying forever.
